# Log Collector · OHT 관제 대시보드 프로토타입

OHT(천장 반송 차량) 로그 수집 시스템 **Log Collector**의 관제 대시보드 디자인 프로토타입입니다.
실제 장비와 연결되지 않으며, 화면 안에서 생성한 가상 데이터로 동작합니다.

> 로그 메시지 본문은 공개용 가상 문구입니다. 실제 장비 로그 형식과 다릅니다.

## 화면

- **전체 관제**: 실시간 레일 맵과 기기 상태 목록. 기기를 고르면 3D 차량 뷰(회전, 부품 선택)와 기기 정보로 전환되고, 레일 위 앞·뒤 차량으로 이동할 수 있습니다.
- **로그 조회**: 원문 검색과 차량·카테고리·판정·날짜/시각(초 단위) 필터, 로그 상세(원문·장비 타임라인).
- **로그 추이**: 조회 가능 범위와 보관량, 로그 건수 추이, 이상 탐지 추이.
- **이상 모아보기**: 본문 규칙 기반 탐지 결과와 규칙 켜고 끄기.

## 실행

```bash
npm install
npm run dev
```

## 기술

React 19, TypeScript, Vite, three.js(@react-three/fiber). 외부 CDN·폰트를 쓰지 않아 사내망에서도 동작합니다.
